Quiz #2, AST到IR+ 转换：整数类型初始化检查
问题背景：考虑FDMJ中的变量。在一般情况下，通过静态程序分析去判断一个变量是否在使用前已经被赋值，是不可计算的。但我们可以使用动态跟踪的方式做此判断，也就是在AST到IR+转换时加入一些代码，在代码运行时进行判断（参考数组类型使用时是否越界的判断方法）。
Coding要求：为简化任务起见，只需要考虑method的int变量（即local int variables，即在这个coding部分不需要考虑class int variables，也不需要考虑任何其他变量类型）。你只能修改ast2ir.cc文件！
1.	使用shadow temp的方法：即对每一个local int variable，额外设定一个temp，利用它跟踪对应的variable是否已经被赋值。不允许使用某个特殊整型哨兵值（比如最小的32位整数-2,147,483,648）表示“未初始化”。
2.	当变量被赋值时，需要加入IR+代码，设定对应的shadow temp为1（初始为0）。
3.	当变量被使用时，需要加入IR+代码，检查对应的shadow temp是否为1。若为1，则代码正常进行，否则调用外部函数exit(-101)（即参数为“-101”）。
4.	在你的HW3-4的基础上，进行上述coding任务，输入是带语义的AST树（*.2-semant.ast文件，输出是对应的 *.3.irp文件）。
5.	你必须在断网并不使用大模型编程辅助的情况下完成coding。
6.	你需要仔细考虑什么情况下，需要插入对shadow temp进行改变或检查的代码。请仔细考虑，保证初始化检查的完整性。
